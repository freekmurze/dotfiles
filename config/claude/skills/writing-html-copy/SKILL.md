# Writing HTML copy

Write clear, direct, specific prose. Apply these rules to all page text you create or revise, including text in prototypes and generated HTML. They apply alongside design and marketing skills, not only when the user explicitly asks for copywriting.

## Writing style

- **No eyebrow headings.** Do not add small category labels above headings. Let the heading identify the subject.
- **No decorative numbering.** Number sections only when their order matters, such as steps in a procedure. Do not number unrelated features for visual effect.
- **No rhythmic or contrasting titles.** Avoid formulas like "Hard to describe. Easy to recognize." State the actual capability or fact instead.
- **Use literal headings.** Describe the content rather than personifying the product or using metaphors and clever imagery.
- **No slogans or clichés.** Avoid "Built for teams that ship", "Unlock your potential", and similar claims that could describe almost any product.
- **Use specific headings.** Replace "A closer look" or "Why it matters" with the subject and the information the section provides.

Write headings like email subject lines, not movie trailers. Prefer information over cleverness. Do not manufacture rhythm, drama, or contrast. Be concrete enough that the copy could not describe any product. Let interesting facts speak for themselves. Sound like a thoughtful human, not a marketing department.

## Writing and review process

1. Read the available product facts and existing page content. Identify what the reader needs to understand or do. Do not invent capabilities, statistics, testimonials, or promises to make the copy more specific.
2. Draft headings that name each section's subject. Write supporting text that explains what the product does, for whom, and under what conditions, using only known facts.
3. Check each heading and paragraph: could this text be pasted onto an unrelated product's page unchanged? Replace generic claims with relevant facts, or remove the text if it adds no information.
4. Review the finished page copy against every writing-style rule above. Remove category labels, decorative numbers, slogans, metaphorical headings, and manufactured contrasts before delivering it. When editing an existing page, keep unrelated copy unchanged unless asked for a full copy review.

## Examples

These examples assume the named capabilities are confirmed product facts, not claims to copy into an unrelated page.

- Instead of an eyebrow "POWERFUL FEATURES" above "Everything you need", use one heading: "Schedule emails and track delivery".
- Instead of "Your team's command center", use "View open tickets and their assignees".
- Instead of "A closer look", use "How failed payments are retried".
- Instead of "Less busywork. More impact.", use "Import subscribers from a CSV file".
